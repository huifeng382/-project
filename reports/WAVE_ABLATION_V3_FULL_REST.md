## Rust 集成决策（仿真预算原则）

> **原则（用户定）**：GNN 的价值 = 节省仿真预算。Rust 部署若还要跑完整波形仿真就失去意义 → **wave 数据只作参考/上限，不用于真实 Rust 部署**。

| 方案 | Rust 侧成本 | 遗憾（full+rest） | 定位 |
|---|---|---|---|
| nowave | 0（不跑波形仿真） | 3.77% | **Rust 部署基线** |
| 真实 ids_avg | 需波形仿真（与 GNN 目的冲突） | 0.55% | 上限参照 |
| **ids_avg 近似公式** | 近零（几个 FLOP） | 待验证 | 候选升级 |
| 25% 覆盖率 | 省 75% 仿真量 | 32.9% | 不可行（已证伪） |
| **粗仿真 ids_avg** | 需 Xyce 但**不省时间**（自适应步长，16.10.2 实测 1.0~1.2×） | 相关性 r≥0.9998 | **已关闭**（无时间收益） |

### ids_avg 近似公式（候选，待验证）

物理：`ids_avg ≈ C_L × ΔV / T_sw`（平均漏极电流 = 输出负载充放电电荷 ÷ 开关时间）

| 量 | 便宜代理（Rust 端网表/静态量可得） |
|---|---|
| C_L | 扇出 × 输入电容 + `parasitic_caps_json` + 连线估 |
| ΔV | `VDD × (1 − exp(−T_sw/(R_on·C_L)))`，R_on 从驱动强度/晶体管尺寸估（捕获 vds_swing 物理） |
| T_sw | 输入 slew + 输出 RC（≈ slew + R_on·C_L） |

**边界**：近似只能恢复「便宜量与真实 ids_avg 相关部分」；晶体管级效应（短路电流/速度饱和/体效应）拿不到 → 期望部分恢复（3.77% → 2-3%？），到不了 0.55%。若近似只用 GNN 已有特征则几乎不加信息（GNN 可自学习该映射）——必须编码新派生量（每门负载×斜率×摆幅、RC 时间常数）。

**验证实验**：① 用数据内真实 ids_avg 拟合近似公式（评估 R²）；② 以近似 ids_avg 作特征训一版测遗憾。遗憾 ≈0.6-1.5% → Rust 端实现；≈3.5% → 不值，用 nowave。

### 粗仿真 vs 全仿真对照（16.9.5，2026-08-30 初测）

**动机**：用少量仿真成本换更准的 ids_avg（wave 特征，Rust 端零仿真的近似公式信息增量有限）。

**初测（OVF，fall 边沿，单 deck）**：

| 指标 | 全精度 (1p/1n) | 粗仿真 (10p/200p) | 差异 |
|---|---|---|---|
| Q_SUPPLY（开关电荷，ids_avg 相关） | -8.836e-15 | -8.759e-15 | 0.87% |
| DELAY | 5.0881e-11 | 5.0881e-11 | 完全一致 |

**初测结论**：粗仿真精度足够（电荷差 0.87%、延迟一致），但**小电路下耗时仅省 ~5%**（Xyce 启动/解析/DCOP 占大头，步长非瓶颈）——「10-50× 加速」假设在小电路不成立；大型电路（瞬态主导）待测。

**全量对照实验（进行中）**：两遍完整 46 电路基准——
1. 全精度（1p/1n + 缓存启用）→ 暖缓存 + 全精度 CSV + 耗时
2. 粗仿真（10p/200p + XYCE_CACHE=0）→ 耗时 + 延迟精度
对比：总/小型(level0-1)/大型(level3-4) 分档耗时 + 粗 vs 全延迟误差。

### 粗 ids_avg vs 全精度 ids_avg 相关性（16.10.2，2026-08-31 实测）

**动机**：粗 pass 作为「决策的延迟」已被轨迹分叉证伪（16.9.5 全量对照）；但粗仿真是否能为 **GNN 的 ids_avg 特征**提供与全精度足够相关的值，此前未测——这正是本次实验。

**方法**：28 deck（7 电路 × 4 vec，OVF/ADD4_OVF/ALU2/COMP4/ENC8/SHIFTER4/AND16，44~260 管），每 deck 自动生成逐管 `.measure tran AVG ID(XUUT:X_6:M_1)`（Xyce 层级分隔符 `:` + MOSFET 电流 `ID()`），跑三种精度：
- `full` = `.tran 1p 1n`（全精度基准）
- `short10` = `.tran 10p 200p`（粗 pass 原配置，短窗口）
- `samewin10` = `.tran 10p 1n`（同窗口只粗化步长——控制变量）

**结果（逐管级，3896 管/组）**：

| 粗配置 | Pearson r | 逐 deck r (min/med/max) | 最小二乘斜率 | 比值范围 |
|---|---|---|---|---|
| short10 (10p 200p) | **0.9998** | 0.9996 / 1.0000 / 1.0000 | 4.933 | 0.06~186.8（个别管） |
| samewin10 (10p 1n) | **1.0000** | 1.0000 / 1.0000 / 1.0000 | 1.000 | 1.000（逐位一致） |

- 7 电路全部 r≥0.9996（short10）/ 1.0000（samewin10）——大小电路无差异
- **samewin10 逐管值与 full 完全一致（斜率 1.0、比值全 1.0）** → 步长粗化（1p→10p）对 ids_avg **零损失**
- short10 的 ~5× 缩放（斜率 4.93）是**窗口缩短（200p vs 1n）**造成的整体缩放，非步长效应；个别管比值极端（0.06/186.8）是窗口截断掉开关脉冲所致

**耗时与步数（决定性发现）**：粗仿真**几乎不省时间**（总加速 1.0~1.2×，不是预想的 5~10×）：

| 配置 | 内部步数（OVF 样例） | 耗时加速比（28 deck 分档） |
|---|---|---|
| full 1p 1n | 104 | — |
| short10 10p 200p | 98 | 1.03~1.11× |
| samewin10 10p 1n | 103 | 1.00~1.20× |

- **原因**：Xyce 瞬态是**自适应步长**——`.tran` 的步长只是上限，开关转换处（20-40ps）无论 1p 还是 10p 都要小步解析，稳态处自动大步；粗化步长上限没有减少实际步数 → 不省时间
- 这与 16.9.5 初测「小电路仅省 5%」一致，并扩展到所有 7 电路

**结论**：
1. **粗 ids_avg 与全精度相关性极强（r≥0.9998）**——作为 GNN 特征**完全可用**（同窗下逐位一致）
2. **但粗仿真没有时间收益**（自适应步长使步数不减少）→ 「粗仿真省预算换 ids_avg」**经济性不成立**
3. 综合 16.9.5 轨迹分叉 + 本次步数结论：**粗 pass 整体无意义，已杀**（用户 2026-08-31 决定）；ids_avg 补特征的正路是**近似拟合（零仿真，R²=0.655）**，粗仿真方案关闭
4. 副产品：Xyce 逐管电流提取语法已破解（`ID(XUUT:X_6:M_1)`，层级 `:` 分隔）——任何需要逐管 ids 的场景可直接用 `.measure tran AVG ID(...)`
