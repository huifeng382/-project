## 0.5 纯数据裁决（2026-09-06，本地诊断，抽样 8,880 行 / 137,332 (row,门) / 5,822 门；脚本 `scripts/diag/_t_wave_{label,decomp,oracle}.py` 临时件）

**测出的事实**
- (row,门) 恒 ≥2 管（n_t==1 = 0%）；n_t==2 占 70.9%，**n_t≥8 占 28.5%**，max 76。55% 组含 <10% of max 近零管；41% 组 ≥3 管同时导通。均值 = 把"导通腿"与"off 漏电腿"一起平均。
- 同 (电路,方向,门) 跨不同 vector，标签 log1p 波动 std 中位 0.14；**active-leg 数 log(n_on) 单独解释该波动的 R² 中位 = 0.844（84% 组 >0.5）** ⇒ 标签的向量间运动主要是"几腿同时通"这个**离散激活态**在驱动，不是 slew/load 幅度。单腿电流漂移 log(max) std 0.232 ≥ log(n_on) 0.176（同量级、次之）。
- identity-oracle（模型完美知静态身份+拓扑，不知每-vector 输入态）池内 R² 0.267、within-(cid,dir,gate) 抖动占总方差 73%（m4 高重复片 92%）。⚠ 仅当**抖动幅度**证，勿当"0.79 上限"读——该口径被 m4 高重复撑大，真实电路级切分含大量组间方差。

**裁决结论**
1. **标签的墙 = 腿数/激活态（输入稳态组合），不是聚合本身、也不是 slew/load 幅度**。两点式锚定（src-slew/out-load）与传导型有效 slew/load 都只是它的**弱代理**。
2. **押甲（晶体管级 node 重做）无据**：wave 每管本就有独立 ids_avg，把管当节点仍不知"这条腿这次通没通"。→ §2 不做。
3. **押乙（delay 线每门 slew/load 当特征）刻度弱**：吃的是腿数以外的那部分 + 单腿电流漂移。→ 旧 ② 降级为次通道，主打换成"激活态/腿数代理"。
4. 残差预期集中在高 n_t / 深堆叠 / 腿跳变大的门——**待 ③ 上模型定位证实**。

## 0.6 模型级定位与三跑裁决（2026-09-07，orca 全量，17.0.14 收口 regime，三者皆 best@ep120 / earlystop@ep160 干净同框）

**测出的事实（§0.5 先验获模型级证实）**
- R1 base 锚 test **0.7861**（m4 .8163 / full .7641 / rest .7792；GBDT15 m4 .2391 与史一致=同切分）→ 17.0.14 收口复现 B2v2 好基座。
- R2 +①rich（stack/parallel）test 0.7870 = **Δ+0.0009 / val +0.0018**；full −.0025 / m4 −.0044 / rest +.0017。
- **③ test 残差按 n_t 分层：n≤2 = 0.801（378k）/ n3-7 = 0.766（30k）/ n≥8 = 0.569（152k，27%）**。

**裁决结论**
1. **① stack/parallel = 判无效**：Δ test +0.0009 噪声级；且 n≥8 层 R² 两跑**逐位同 0.5689** → 静态结构列对残差主人群零信息（与 §0.5 判断一致：那池子是激活态，不是静态结构）。① 划掉。
2. **③ 闸门 PASS**：残差确集中在高 n_t 深堆叠门（n≤2 0.80 → n≥8 0.57，塌 −0.23）→ **②' 激活锥/腿数代理值投**（瞄准 152k/560k=27% 的最大残差池）。
3. **R3 配置陷阱**：`CONE_V2=0` **单开 = 关掉锥体**（锥体 v1 须 `CONE_FEAT=1`+`CONE_V2=0` 双开）。R3 实际 no-cone 0.7410 → **意外复核"锥体贡献 +0.045"**（vs R1，≈史 +0.044）。serve 端 v1-vs-v2 定档仍未真跑。
4. 附产物：R1/R2 的 ckpt + `resid_R1/R2_base/rich_17015.parquet`（560k 行，含 n_t/stack/parallel/cone 各列）已在服务器，②' 开发期可作 n≥8 池锥深/腿数细定位数据源。

## 0.7 ②' 激活锥/腿数代理 R4 跑完（2026-09-07 · 17.0.16 base+CONE_PIN · 同 R1 regime 同切分）

**测出的事实（R4 vs R1 base 锚，同 560,242 行切分、确定性 seed → Δ 无采样噪声）**
- test R² **0.7883** vs R1 0.7861 = **Δ +0.0022**；best_val 0.7827@ep120（死尾空转至 ep160，17.0.18 起取消）。
- n_t 分层：n≤2 0.8022（378k）/ n3-7 0.7655（30k）/ **n≥8 0.5778（152k）= 目标池 Δ +0.0089**（vs R1 0.5689；R2① 同池逐位 0.0000）。
- 分桶：rest +0.0034 / 子源 full −0.0030 / **m4 −0.0049**（0.8163→0.8114）。

**裁决结论**
1. **②' 机制确认**：增益精确打进 n≥8 残差主人群（+0.009），n≤2/n3-7 不动 → §0.5（log(n_on) 驱动标签运动）+ ③ 分层预言获模型级证实。CONE_PIN 确把"激活腿数"的 **sim-free 代理**喂给了深堆叠门。对照 R2① 同池零信息 → 腿级锥与静态结构列对残差池的信息正交性实锤（残差池是激活态：腿锥看得见、静态结构看不见）。
2. **headline 边际小 + 有回吐**：full test Δ +0.0022（R4 0.7883 = 同 120ep 现行最佳）；增益在 rest 深堆叠池赚、m4 −0.0049 还 → 非纯免费。量级比真台阶（锥体 +0.045/容量 +0.041）小一个数量级。
3. **下一步 = R5 专化裁决，目标线升为 0.5778**：共享+腿已达 n≥8 0.5778 → R5（base 专化 ge8）须先超 0.5778 才比"直接上 R4 共享模型"有增量；R5 若再想吃腿特征 = R6 ge8+CONE_PIN（勿与 R1 锚混开）。采用与否待 **serve 端腿级特征成本（Rust driver∈d1 输入脚计数）** 与 R5 结果一并定。

## 0.8 n≥8 专化 R5/R6 + 复合路由 跑完（2026-09-08 · 17.0.17/19 专化 · 17.0.20 零训练复合 · 多 seed #35 已定档见 §0.10）

**测出的事实**（n≥8 池 152,279 test 行 / mean_y 0.248，与 R1/R4 的 n≥8 层同池逐位可比；同收口 regime，17.0.18/19 纯省时/内存无数值差）
- 专化模型 `TIER_ONLY=ge8`（GBDT+GNN 只在 n_t≥8 采样门上训/评）：**R5 base = 0.6053 / R6 +CONE_PIN = 0.6102**（池内 R²）。共享对照：R1 0.5689 / R4 0.5778。
- 2×2（池内）：专化轴 **R5−R1 = +0.0364 / R6−R4 = +0.0324**（误差 −8~10%）；腿轴专化内 R6−R5 = +0.0049（< 共享内 R4−R1 +0.0089）。
- 复合路由（部署形态 = 按 n_t 路由，n<8 用共享 pred + ge8 用专化 pred，同 560,242 行/同基线）：**B = R4(n<8)+R6(ge8) = 0.7912**（Δ vs R4 +0.0029 / vs 史高 B2v2long +0.0019）；A R1+R5 0.7894 / D R1+R6 0.7898 / C R4+R5 0.7907。

**裁决结论**
1. **专化 = 目标对齐大赢（深池）**：同一批 ge8 训练行、同一 regime，只是不再被 73% 浅门稀释目标 → n≥8 池 +0.036。**深池绝对值仍 0.60、远低于浅门 0.80** → 结构墙（激活态残差，§0.5）仍在，专化压掉约一成误差但没拆墙；状态特征辅助已判死（§2）。
2. **复合路由 = headline 兑现但小幅**：B 0.7912 = 全口径新最佳，Δ +0.0029（vs 单模型 R4）→ 与 R4 的 +0.0022 同量级；每层机制（锥体/腿/专化）在 headline 上都是 +0.002~0.005。部署形态 = R4 共享+腿（n<8）+ R6 专化+腿（ge8）双模型按 n_t 路由（n_t = 静态拓扑层，serve 可得）；双模型 + n_t 的落地成本最后谈采用。

## 0.9 R² 优化线收口（2026-09-08 · 零训练桶分解 + 锥轴探针 · 定案 A = 0.85 不达、转 serve 判定）

**触发**：B=0.7912（§0.8）后评估"再往 0.85 投"值不值。零训练，纯读 R4/B resid 三探针（`scripts/diag/_t_{bucket_cost,depth_probe,cone_probe}.py`）。**先想清楚再跑**——桶分解先指向 n≤2，但 depth 探针错轴（静态逻辑深度当"埋没度"），改锥轴后结论反转，见"方法论教训"。

**桶分解（`_t_bucket_cost`，R4 单 & B 复合同表；SSE 占全局 SS 份额 = "若该桶归零 headline 抬升"）**
- **n≤2 = 82%**（378k 行 67.5%，mean_y 0.374）→ 桶归零 headline 上 0.96；n3-7 = 0.13%；**n≥8 = 4%**（152k 行 27.2%，mean_y 0.248）→ 深桶完美也只到 **0.8258**。→ 表面矛头全指 n≤2。

**锥轴探针（`_t_cone_probe`，n≤2 按 `incone` → 锥内按 `cone_down` 分箱）**
- n≤2 0.8022 = **两群混合**：
  - **out-cone（不在本次切换锥）** 231,948 行 61%，mean_y 0.101 近零目标：R² 0.0879 纯口径假象（真实误差小），SSE 占 n≤2 14.4%；
  - **in-cone（切换门）** 146,340 行 39%，mean_y 0.807：池内 0.6455 又被 mean 随 cone_down 的趋势（0.44→1.11）抬高，**分箱后 within-bin R² 只 0.26–0.50**（cd0.0-0.2 = 0.2568 / 0.2-0.4 = 0.4992 / 0.4-0.6 = 0.5012 / 0.6-0.8 = 0.3341；cd0.0 src 本体 n=122）。
  - **全局误差最大单块 = cd 0.4–0.6 中锥高电流门**：68,349 行、mean_y 1.110、**占锥内 SSE 69.4%**（即 n≤2 内 ~86% 的 SSE 中的 69%）、within-bin R² 仅 0.50。
  - corr(|残差|², cone_down)=**+0.213**、corr(|残差|², 静态 depth)=+0.211 → 传播/埋没轴对残差解释弱。

**裁决结论（定案 A = R² 线收口）**
1. headline ~0.79 的相当成分是**群体分离**（idle-vs-active 判别 + 电流量级分层），不是激活门电流的精细预测。**激活门 per-class R² ~0.5–0.6，跨 深堆叠（§0.8 专化 0.60）& 浅层激活门（分箱 0.26–0.50）都是墙**（状态特征判死 §2 照旧）→ sim-free 现有特征族（锥体/腿/专化/静态结构）已达信息墙。
2. **exact-log1p pooled R² ≥0.85 不达**。唯一机制自洽但探针支持弱的未试轴 = logical-effort 沿锥逐门传到（per-gate 到达 slew/load，sim-free/STA/Rust 可行）；期望只 0.82–0.83 且须把 cd0.4–0.6 主残差块砍 20–30%——**不入主动池，收档于此**，serve 判定后仍要博再议。
3. **B = 0.7912（R4 n<8 + R6 ge8 路由）即 R² 线部署形态**。剩余 = **#35 多 seed 集成**（已完成，§0.10：集成复合 0.7935）→ 转 **serve 指标 / 相对误差**判定，**不再投 R² 训练**。

**方法论教训（入档）**：原 `_t_depth_probe` 用静态逻辑深度（主输入最长路径）当"埋没度" = 错轴——本任务**一行 = 单次开关事件**，正确传播轴 = 距本次切换 src 的锥内位置（cone_down）；深堆叠低 R² 是**激活态墙**（浅层激活门同墙），不是"静态埋深墙"。depth 轴读数作废，结论以 cone 轴为准。

## 0.10 多 seed 集成定档（2026-09-10 · 4×4 全配对 · 零训练 · `_t_ensemble.py`）

- 波1 R4 共享+腿 SEED1-3 + 波2 R6 专化+腿 SEED1-3，各 resid 按行逐位对齐（len/n_t/y 校验 OK，560,242 test 行）。
- 共享侧 full R² 4 seed = 0.7883/0.7867/0.7926/0.7888 → mean **0.7891 ± 0.0022**；专化侧 ge8 = 0.6102/0.6011/0.6091/0.5980 → mean **0.6046 ± 0.0052**（seed0 最高，专化侧抖动 ≈2× 共享侧）。
- 4×4 全配对复合 mean **0.7914 ± 0.0020**（0.7890–0.7951，seed0+seed0=0.7912）；对角 = 全配对 mean → **无配对效应**；**B=0.7912 居正中央 → +0.0029 非 seed 手气**。
- 集成复合（每侧 4-seed 平均）= **0.7935**（vs B 单模型 +0.0023）。
- **裁决**：集成增益 +0.0023，对 0.85 墙无松动 → 侧证 §0.9 定案 A。**R² 线最终 = B 双模型按 n_t 路由：单 seed 0.7912 / 集成 0.7935**。**R² 线程至此整体关闭**，转 serve 判定。
- **Caveat**：GPU scatter_add 非确定性 → 同 SEED 重跑 R² 有 ~0.005 抖动（首轮 env 名误写那批 0.6044/0.6041/0.6080 vs 本轮 0.6011/0.6091/0.5980，env 名不影响训练数值）→ 多 seed 散布含**跑批噪声**，解读为"部署总方差"。另：首轮波2 env 名误写（`CKPT`/`DUMP` vs 代码实读 `SAVE_CKPT`/`DUMP_RESID`）只出 R² 无 resid，修 `_t_ensemble.py` n<8 切片 bug 后重跑落盘。详见 `IDS_AVG_GNN.md` §4.9。

### ② 激活锥 / 腿数代理特征 —— ✅ R4 已跑：机制确认 / headline 边际小（§0.7）
- **内容**：给每门编码"这次向量里它的**激活态/导通腿**代理"。最贴 serve 可行的一档 = **输入脚级锥粒度**：现锥体 BFS（从 src 出发的切换锥）已有"该门在不在锥上"的粗量（= +0.044 的来源）；升级为对该门**每条输入脚**分别标"是否落在切换锥 / 距 src 级数"，得到"哪几路输入被这次切换拉动 → 哪组堆叠腿会通"的向量级特征。
- **机理（数据主导）**：§0.5 —— 同门跨 vector 标签运动 **84% 由 log(n_on) 解释**；§0.6 ③ —— 残差确集中 n≥8 深堆叠门（0.57 vs 0.80）。喂"激活腿数"的近亲信号 ≈ 直接对准 R² 残差的最大单一来源。旧 ②"传导有效 slew/load"降为**次通道**（想加时作辅助列，不做独立主打）。
