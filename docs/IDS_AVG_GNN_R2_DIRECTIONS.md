## 0. 现状坐标与推断依据（为什么下一步是"解释噪声"而非"调训练"）

全量里程碑（`IDS_AVG_GNN.md` §4.4/§4.5）：

| run | test R² | m4 桶 | 说明 |
|---|---|---|---|
| 17.0.1 基线 | 0.7012 | 0.6583 | K3/h96/45ep |
| A2 容量 | 0.7424 | 0.7016 | K5/H160/E32 → 容量 +0.041 |
| B2 锥体 v1 | 0.7866 | 0.8076 | +锥体特征 → +0.044 |
| B2v2long | 0.7893 | **0.8235** | 220ep 长程，v2=m4 特化 |

关键观测：
1. **每个配置 train R² ≈ test R²**；220ep 追长 test 仅 +0.0016（噪声级）⇒ 非欠拟合追不动，剩余为不易解释的标签/上下文噪声。
2. 历史上每次真实上台阶（容量 +0.041、锥体 +0.044）本质 = **把一部分"看着像噪声"的方差解释掉了**。
3. 推论：0.789 再往上只剩 **(a) 喂更多能解释表观噪声的特征；(b) 削预测方差（集成/EMA）**。
4. ⚠ 标签为门内所有晶体管 `ids_avg` 的**均值**（`_fit_idsavg_gnn_server.py`）——若 wave 同时含非导通支路管子，均值自带构造性缩放。

## 0.5 纯数据裁决（2026-09-06，本地诊断，抽样 8,880 行 / 137,332 (row,门) / 5,822 门；脚本 `scripts/diag/_t_wave_{label,decomp,oracle}.py` 临时件）

**测出的事实**
- (row,门) 恒 ≥2 管（n_t==1 = 0%）；n_t==2 占 70.9%，**n_t≥8 占 28.5%**，max 76。55% 组含 <10% of max 近零管；41% 组 ≥3 管同时导通。均值 = 把"导通腿"与"off 漏电腿"一起平均。
- 同 (电路,方向,门) 跨不同 vector，标签 log1p 波动 std 中位 0.14；**active-leg 数 log(n_on) 单独解释该波动的 R² 中位 = 0.844（84% 组 >0.5）** ⇒ 标签的向量间运动主要是"几腿同时通"这个**离散激活态**在驱动，不是 slew/load 幅度。单腿电流漂移 log(max) std 0.232 ≥ log(n_on) 0.176（同量级、次之）。
- identity-oracle（模型完美知静态身份+拓扑，不知每-vector 输入态）池内 R² 0.267、within-(cid,dir,gate) 抖动占总方差 73%（m4 高重复片 92%）。⚠ 仅当**抖动幅度**证，勿当"0.79 上限"读——该口径被 m4 高重复撑大，真实电路级切分含大量组间方差。

**裁决结论（据此改了 §1/§2）**
1. **标签的墙 = 腿数/激活态（输入稳态组合），不是聚合本身、也不是 slew/load 幅度**。两点式锚定（src-slew/out-load）与传导型有效 slew/load 都只是它的**弱代理**。
2. **押甲（晶体管级 node 重做）无据**：wave 每管本就有独立 ids_avg，把管当节点仍不知"这条腿这次通没通"——攻击的是聚合方式，不是激活问题。→ §2 不做。
3. **押乙（delay 线每门 slew/load 当特征）刻度弱**：吃的是腿数以外的那部分 + 单腿电流漂移，量有但非主打。→ 旧 ② 降级为次通道，主打换成"激活态/腿数代理"特征。
4. 残差预期**集中在高 n_t / 深堆叠 / 腿跳变大的门**——待 ③ 上模型定位证实后再投 ②'。

## 1. 候选方向（按性价比排序，非必投序）

### ① stack / parallel 已算好却没喂 —— 近乎免费，仍建议先做
- **内容**：`build_static_graph` 的 `mode` 从默认 `'base'` 提 `'rich'`，每门静态特征带上 `stack`（串链深）与 `parallel`（并联支数）；`N_CONT_BASE` 7→9。
- **机理（数据更新）**：§0.5 把 n_t≥8 的堆叠门钉成标签抖动主人群——stack/parallel 正是这群门**电流怎么在串/并联腿间分**的静态描述，是模型能见腿结构的零成本通道。`'base'` 只含 n_t，**stack/parallel 两列没进 ns**（`graph_builder.py:280/405-411`）。
- **代码面**：`STRUCT_MODE='rich'` + `N_CONT_BASE 7→9`。~2 行。确认 rich 与 base 前 7 通道逐位一致。
- **预期**：+0.003~0.015；serve 侧**零成本**（纯 cell 名可得）。

### ② 激活锥 / 腿数代理特征 —— 数据主打的新头部（取代旧"传导有效 slew/load"）
- **内容**：给每门编码"这次向量里它的**激活态/导通腿**代理"。最贴 serve 可行的一档 = **输入脚级锥粒度**：现锥体 BFS（从 src 出发的切换锥）已有"该门在不在锥上"的粗量（= +0.044 的来源）；升级为对该门**每条输入脚**分别标"是否落在切换锥 / 距 src 级数"，得到"哪几路输入被这次切换拉动 → 哪组堆叠腿会通"的向量级特征。
- **机理（数据主导）**：§0.5 —— 同门跨 vector 标签运动 **84% 由 log(n_on) 解释**，n_on 由该门输入稳态组合决定；喂"激活腿数"的近亲信号（输入脚级锥命中）≈ 直接对准 R² 残差的最大单一来源。旧 ②"传导有效 slew/load"目标只是腿数以外的 16% + 单腿电流漂移（std 有量但刻度弱），降为**次通道**（想加时作为②'的辅助列，不做独立主打）。
- **代码面**：cone BFS 现成机制扩展；per-sample 静态可达。成本 ≈ cone BFS 同级。
- **预期**：锥体已在 rest/m4 吃 +0.044，细化版瞄准其未覆盖的腿跳变部分；serve 成本**同锥体**（Rust 需补锥/距离特征，未估=未决——与 B2 serve 采用是同一个未决项）。
- **前置**：先跑 ③ 定位证实残差真集中高 n_t/深堆叠，再投。

### ③ 残差定位诊断 —— ③ 是投 ②' 前的闸门
- **内容**：跑一次推理 + dump 每样本门属性（n_t/stack/parallel/锥深/方向/load 分位），算残差 R² 按 **n_t 档**与**锥深档**的分布。
- **机理**：§0.5 纯数据已给先验——若残差随 n_t 升而恶化、集中深堆叠，②' 值投；若均匀分布则 ②' 白投。§0.5 已把旧 ③-(a)"门内离差/标签抖动"量化掉大半，**剩下的核心 = (b) 残差分层**。
- **前置**：`best_sd` 现只在内存（`_fit_idsavg_gnn_server.py`），需加 ckpt 落盘 + 属性 dump（小改动，与 ④ 共用）。
- **成本**：无训练，一次前向（分钟级）。

### ④ 多 seed 集成 —— 正交、零风险（数据不改其定位）
- **内容**：同配置多 seed 训练，预测取均值（或训练期权重 EMA）。削的是**估计器方差**；标签内腿数抖动（§0.5）对 serve 侧近似不可约，故上限不高，但纯赚、与其余方向正交。
- **前置**：加 `SAVE_CKPT` 开关 + seed 可配（`torch.manual_seed` 现写死 0）。

### ⑤ GBDT15 混合 / stacking —— 研究上限用，非落地件
- **内容**：把每门 GBDT15 预测列（或残差）当节点特征。R² 大概率再涨但 **serve 端不可用**。
- **说明（数据后）**：更便宜的"顶天到哪"探针已是 §0.5 + ③；⑤ 更偏独立交叉验证，仍非落地件——投前明确目的。

## 2. 明确不做
- **晶体管级 node 重做（押甲）**：§0.5 裁决无据——管级预测仍缺"该腿这次通没通"的激活态，改节点粒度不解激活问题。删除候选。
- **押乙纯 "delay 线每门 slew/load 当主打特征"**：刻度弱（§0.5 结论 3）。不立为主打；作为②'次通道可附。
- 再加容量 K/H：220ep 追长 ≈ 0 已证边际小。
- 退火/调度**不作为提 R² 的杠杆**（17.0.14 LR_TMAX/STOP_EPS 属墙钟/收口控制，非精度改动）。
- **GSZ>1**：钉死勿开。
- EPOCHS：**上不封顶，EPOCHS 只当安全上限**；靠更快早停收口。17.0.14 默认 = B2v2 好基座 + `LR_TMAX=120` + `STOP_EPS=2e-3` + `PATIENCE=40` + `EPOCHS=400`（安全上限，须 > LR_TMAX）。⚠ 复现历史须显式 env 传旧值，裸跑不再=17.0.1。
- ⚠ 比对口径：候选与 220ep 基线（0.7893）比，epoch 混淆 ≤+0.002；最稳 = 候选同跑一个同 epoch 的 B2v2 基线对照。

## 3. 建议首投顺序
1. **① stack/parallel**（半小时见分晓，改 2 行，serve 零成本）→ 确认"门内静态结构还剩多少可榨"。
2. **③ 残差定位**（ckpt+dump，一次推理）→ 验证 §0.5 先验：残差集中高 n_t/深堆叠。
3. ③ 证实 → 上 **② 激活锥/腿数代理**（瞄准 n_on 的单一最大残差源）。
4. **④ 多 seed** 随手收尾。⑤ 仅研究用途。
