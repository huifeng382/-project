## 0. 现状坐标与推断依据（为什么下一步是"解释噪声"而非"调训练"）

全量里程碑（`IDS_AVG_GNN.md` §4.4/§4.5）+ 17.0.15 三跑：

| run | test R² | m4 桶 | 说明 |
|---|---|---|---|
| 17.0.1 基线 | 0.7012 | 0.6583 | K3/h96/45ep |
| A2 容量 | 0.7424 | 0.7016 | K5/H160/E32 → 容量 +0.041 |
| B2 锥体 v1 | 0.7866 | 0.8076 | +锥体特征 → +0.044 |

| **R2 同 +① rich** | 0.7870 | 0.8119 | ① stack/parallel：Δ test +0.0009 → 判无效（§0.6） |

关键观测：
1. **每个配置 train R² ≈ test R²**；220ep 追长 test 仅 +0.0016（噪声级）⇒ 非欠拟合追不动，剩余为不易解释的标签/上下文噪声。
2. 历史上每次真实上台阶（容量 +0.041、锥体 +0.044）本质 = **把一部分"看着像噪声"的方差解释掉了**。
3. 推论：0.789 再往上只剩 **(a) 喂更多能解释表观噪声的特征；(b) 削预测方差（集成/EMA）**。
4. ⚠ 标签为门内所有晶体管 `ids_avg` 的**均值**（`_fit_idsavg_gnn_server.py`）——若 wave 同时含非导通支路管子，均值自带构造性缩放。
5. **17.0.15（§0.6）**:静态结构列（stack/parallel）喂了没用（n≥8 层零变化）→ 残差池 = 高 n_t 深堆叠门的**激活态**；③ 闸门 PASS → **②' 激活锥 = 现主投**。

## 0.5 纯数据裁决（2026-09-06，本地诊断，抽样 8,880 行 / 137,332 (row,门) / 5,822 门；脚本 `scripts/diag/_t_wave_{label,decomp,oracle}.py` 临时件）

**测出的事实**
- (row,门) 恒 ≥2 管（n_t==1 = 0%）；n_t==2 占 70.9%，**n_t≥8 占 28.5%**，max 76。55% 组含 <10% of max 近零管；41% 组 ≥3 管同时导通。均值 = 把"导通腿"与"off 漏电腿"一起平均。
- 同 (电路,方向,门) 跨不同 vector，标签 log1p 波动 std 中位 0.14；**active-leg 数 log(n_on) 单独解释该波动的 R² 中位 = 0.844（84% 组 >0.5）** ⇒ 标签的向量间运动主要是"几腿同时通"这个**离散激活态**在驱动，不是 slew/load 幅度。单腿电流漂移 log(max) std 0.232 ≥ log(n_on) 0.176（同量级、次之）。
- identity-oracle（模型完美知静态身份+拓扑，不知每-vector 输入态）池内 R² 0.267、within-(cid,dir,gate) 抖动占总方差 73%（m4 高重复片 92%）。⚠ 仅当**抖动幅度**证，勿当"0.79 上限"读——该口径被 m4 高重复撑大，真实电路级切分含大量组间方差。

**裁决结论**
1. **标签的墙 = 腿数/激活态（输入稳态组合），不是聚合本身、也不是 slew/load 幅度**。两点式锚定（src-slew/out-load）与传导型有效 slew/load 都只是它的**弱代理**。
2. **押甲（晶体管级 node 重做）无据**：wave 每管本就有独立 ids_avg，把管当节点仍不知"这条腿这次通没通"。→ §2 不做。
3. **押乙（delay 线每门 slew/load 当特征）刻度弱**：吃的是腿数以外的那部分 + 单腿电流漂移。→ 旧 ② 降级为次通道，主打换成"激活态/腿数代理"。
4. 残差预期集中在高 n_t / 深堆叠 / 腿跳变大的门——**待 ③ 上模型定位证实**。

## 0.6 模型级定位与三跑裁决（2026-09-07，orca 全量，17.0.14 收口 regime，三者皆 best@ep120 / earlystop@ep160 干净同框）

**测出的事实（§0.5 先验获模型级证实）**
- R1 base 锚 test **0.7861**（m4 .8163 / full .7641 / rest .7792；GBDT15 m4 .2391 与史一致=同切分）→ 17.0.14 收口复现 B2v2 好基座。
- R2 +①rich（stack/parallel）test 0.7870 = **Δ+0.0009 / val +0.0018**；full −.0025 / m4 −.0044 / rest +.0017。
- **③ test 残差按 n_t 分层：n≤2 = 0.801（378k）/ n3-7 = 0.766（30k）/ n≥8 = 0.569（152k，27%）**。

**裁决结论**
1. **① stack/parallel = 判无效**：Δ test +0.0009 噪声级；且 n≥8 层 R² 两跑**逐位同 0.5689** → 静态结构列对残差主人群零信息（与 §0.5 判断一致：那池子是激活态，不是静态结构）。① 划掉。
2. **③ 闸门 PASS**：残差确集中在高 n_t 深堆叠门（n≤2 0.80 → n≥8 0.57，塌 −0.23）→ **②' 激活锥/腿数代理值投**（瞄准 152k/560k=27% 的最大残差池）。
3. **R3 配置陷阱**：`CONE_V2=0` **单开 = 关掉锥体**（锥体 v1 须 `CONE_FEAT=1`+`CONE_V2=0` 双开）。R3 实际 no-cone 0.7410 → **意外复核"锥体贡献 +0.045"**（vs R1，≈史 +0.044）。serve 端 v1-vs-v2 定档仍未真跑。
4. 附产物：R1/R2 的 ckpt + `resid_R1/R2_base/rich_17015.parquet`（560k 行，含 n_t/stack/parallel/cone 各列）已在服务器，②' 开发期可作 n≥8 池锥深/腿数细定位数据源。

## 1. 候选方向（按状态排序）

### ② 激活锥 / 腿数代理特征 —— 🎯 现主投（③ 闸门 2026-09-07 已过）
- **内容**：给每门编码"这次向量里它的**激活态/导通腿**代理"。最贴 serve 可行的一档 = **输入脚级锥粒度**：现锥体 BFS（从 src 出发的切换锥）已有"该门在不在锥上"的粗量（= +0.044 的来源）；升级为对该门**每条输入脚**分别标"是否落在切换锥 / 距 src 级数"，得到"哪几路输入被这次切换拉动 → 哪组堆叠腿会通"的向量级特征。
- **机理（数据主导）**：§0.5 —— 同门跨 vector 标签运动 **84% 由 log(n_on) 解释**；§0.6 ③ —— 残差确集中 n≥8 深堆叠门（0.57 vs 0.80）。喂"激活腿数"的近亲信号 ≈ 直接对准 R² 残差的最大单一来源。旧 ②"传导有效 slew/load"降为**次通道**（想加时作辅助列，不做独立主打）。
- **代码面**：cone BFS 现成机制扩展（per-sample 静态可达）；成本 ≈ cone BFS 同级。
- **前置**：~~先跑 ③ 证实~~（**已过**，§0.6）。
- **预期**：锥体粗量已在 rest/m4 吃 +0.044；细化版瞄准其未覆盖的 n≥8 腿跳变部分。serve 成本**同锥体**（Rust 需补锥/距离特征，未估=未决）。

### ④ 多 seed 集成 —— 正交、零风险（保留）
- **内容**：同配置多 seed 训练，预测取均值（或训练期权重 EMA）。削估计器方差。
- **状态**：此轮用户明确**不加 seed**（2026-09-07）；`SEED` 旋钮未加（`torch.manual_seed(0)` 写死）。留作低优先随手项——需要时加 ~4 行。
- **机理**：标签内腿数抖动（§0.5）对 serve 侧近似不可约，上限不高，纯赚、与其余方向正交。

### ⑤ GBDT15 混合 / stacking —— 研究上限用，非落地件（保留原判）
- **内容**：把每门 GBDT15 预测列（或残差）当节点特征。R² 大概率再涨但 **serve 端不可用**。
- **说明**：更便宜的"顶天到哪"探针已是 §0.5 + ③；⑤ 更偏独立交叉验证。投前明确目的。

### ① stack / parallel —— ✅ 已跑：判无效（17.0.15 R2，§0.6 划掉）
- 曾视为近乎免费候选（rich 模式喂 stack/parallel 两列，serve 零成本）。
- **结果**：Δ test +0.0009 / val +0.0018；n≥8 层 R² 逐位同 base 0.5689 → 静态结构列对残差主人群零信息。不重投。

## 2. 明确不做
- **晶体管级 node 重做（押甲）**：§0.5 裁决无据。
- **押乙纯 "delay 线每门 slew/load 当主打特征"**：刻度弱（§0.5 结论 3）。不立为主打；作为②'次通道可附。
- 再加容量 K/H：220ep 追长 ≈ 0 已证边际小。
- 退火/调度**不作为提 R² 的杠杆**（17.0.14 LR_TMAX/STOP_EPS 属墙钟/收口控制，非精度改动）。
- **GSZ>1**：钉死勿开。
- EPOCHS：**上不封顶，EPOCHS 只当安全上限**；靠更快早停收口。17.0.14 默认 = B2v2 好基座 + `LR_TMAX=120` + `STOP_EPS=2e-3` + `PATIENCE=40` + `EPOCHS=400`（安全上限，须 > LR_TMAX）。⚠ 复现历史须显式 env 传旧值。
- ⚠ 比对口径：候选与 220ep 基线（0.7893）比，epoch 混淆 ≤+0.002；**最稳 = 候选同跑一个同 epoch 的 base 对照**（17.0.15 R1 即此锚，best@120/stop@160）。
- ⚠ **配置陷阱（17.0.15 R3）**：锥体 v1 ≠ `CONE_V2=0` 单开——那是**关锥体**。v1 须 `CONE_V2=0 CONE_FEAT=1` 双开。且 dump 守卫 bug `N_EXTRA>=7`→应 `>=10`（无锥通道 run 一开 dump 就崩），下轮随 ②' 一并修 + log 头加配置回显防静默误配。
